# Moodle Dark Theme for Hokkaido Information University

## 日本語

本学のMoodle(polite.do-johodai.ac.jp)にはダークテーマがないため、その代替として作成したカスタムテーマです。

### 導入方法

1. ブラウザに拡張機能「**Stylus**」をインストールします。
2. Stylusで新しいスタイルを作成し、適用先のサイト欄に `polite.do-johodai.ac.jp` と入力します。
3. このリポジトリの `copy_this.css` を開き、中身を**すべてコピー**します。
4. コピーした内容をStylusのコード入力欄に**貼り付けて**保存します。

### 注意事項

このテーマは現在**開発中(WIP)**のため、表示崩れなどの不具合が残っている可能性があります。
不具合を見つけた場合は、学籍番号 `2621102` 宛にメールでご連絡ください。

## English

Our school's Moodle (polite.do-johodai.ac.jp) has no dark theme, so this is a custom alternative.

### Installation

1. Install the **Stylus** extension in your browser.
2. Create a new style in Stylus and enter `polite.do-johodai.ac.jp` as the site the style applies to.
3. Open `copy_this.css` in this repository and **copy its entire contents**.
4. **Paste** it into Stylus's code editor and save.

### Notes

This theme is still a **work in progress (WIP)**, so you may run into bugs or visual glitches.
If you find any, please send an email to my school ID `2621102`.
